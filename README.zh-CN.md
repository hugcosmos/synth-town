# ⚗️ 元素合成小镇

[English](./README.md) | **简体中文**

一个单文件、零依赖的浏览器合成经营小游戏。双击 `index.html` 即可游玩，无需安装任何东西。

## 玩法

- 🎰 **开局幸运抽取**：抽取四大基础元素（土/水/火/气，各 10~99 个）+ 少量启动金币
- ⚗️ **点击/拖拽合成**：轻点元素自动填入下一个空槽，或拖拽到指定槽；两个元素组合发现 20+ 配方（土+水=泥、泥+火=砖……），合成免费。**批量合成**随进度解锁：资产>100→1~5个，>1000→1~20个，>10000→1~100个
- 🏗️ **建造小镇**：攒够建材建造小屋、商铺、花园、豪宅（持续产出金币）、市政厅（全镇产出+10%全局加成，自身不产出）。**🧰宝箱**作为豪宅、市政厅等高级建筑的建造材料
- 🗺️ **小镇地图**：建成小屋+商铺后解锁，可视化地图含 5 大分区（平原/山脚/林间/河岸/市中心）各有成本/产出系数；顶部统计栏（总建筑/金币产出/已开发区域）+ 建筑徽章 + 分区建筑网格展示
- 🧬 **生命线（隐藏玩法）**：⚡能量 + 高级"死路元素" = 🧬生命，生命值由材料层级决定；孕育宠物（猫/兔/狗/牛/马），**满级生命 1/100 出 🐼熊猫**
- 🐾 **宠物养成**：给宠物起名（最多15字符，英文模式下自动用英文名）、记录出生时辰（分钟→小时→天自适应）、亲密度系统（0-100，每10点=1级=+0.5%产出加成，满级解锁自定义头像）、分物种口粮、饱食度/生命值、宠物医院（生病不死可治疗）、物种基础加成 +1%~+5% + 亲密度额外加成。网格卡片布局，喂食/互动/治疗在卡片内一键完成
- 🛒 **元素商店**：用金币购买3级及以下常见元素，价格=层级×5。**批量购买**与合成共享同一档阶级限
- 🧙‍♂️ **长老NPC按Tab差异化提示**：合成页智能推荐可合成配方、小镇页建筑收益提示、商店页规则说明、宠物页实际加成明细（含亲密度计算：每10点=1级=+0.5%）；点击长老可提前关闭，切换Tab自动弹出提示

## 特性

- 单 HTML 文件，纯静态，可部署到任意静态托管（GitHub Pages / Cloudflare Pages）
- 🌐 **中英文双语**：顶部导航或开屏页均可切换，元素名、建筑名、NPC台词、设置、所有UI文本完整本地化
- localStorage 自动存档，离线收益封顶 1 小时
- 📦 存档副本：带版本号迁移的 JSON 导出/导入（当前 v3），可选**完整版**（含宠物自定义头像）或**轻量版**（不含头像，文件更小）。导入自动检测旧版本并迁移
- 🎨 4 套内置主题配 AI 生成背景图（紫夜/森绿/暖沙/雪境），另有第 5 个「自定义」槽位，上传任意图片即可作为游戏背景
- 🖼️ 自定义背景上传：选择任意图片，自动压缩到 ≤1920px，存 IndexedDB（不占存档空间）
- 🖼️ 自定义素材包：`theme.json` 导入宠物/元素/地块贴图，存 IndexedDB，自动压缩，回落内置卡通图再回落 emoji
- 🐾 6 种内置卡通宠物头像 + 待机动画，亲密度满级(Lv.10)解锁自定义头像上传
- 📱 移动端适配：紧凑两行式导航（避开容器UI遮挡），页面自然滚动，元素全部展示无需内部滚动条
- 📕 **小红书小程序适配版**：独立分发版本，针对小红书内置浏览器优化：移除JSON导入导出、移除`window.prompt`（改用自定义Modal）、移除行内`onclick`、安全区内边距适配小红书头部按钮。位于 `Desktop/synth-town-minitool/`

## 自定义素材包格式

```json
{
  "pets":     { "cat": "data:image/png;base64,..." },
  "elements": { "brick": "data:image/png;base64,..." },
  "regions":  { "river": "data:image/png;base64,..." }
}
```

规格：宠物/元素 128×128、地块 512×256、单张 ≤200KB（超规格自动重采样压缩）。

## 部署

**GitHub Pages**：仓库 Settings → Pages → 选择 `main` 分支即可。

**Cloudflare Pages**：连接仓库，构建命令留空，输出目录 `/`。

**小红书小程序**：使用预打包的 `synth-town-xiaohongshu.zip`（从 `Desktop/synth-town-minitool/` 生成）。该版本移除了JSON导入导出和`window.prompt`以适配小红书容器限制。
